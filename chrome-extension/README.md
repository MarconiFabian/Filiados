# ML Afiliados Sender 1.0.11

Extensão oficial do Afiliados Pro para Chrome.

## Novidades

- Central de diagnóstico integrada ao aplicativo.
- Histórico detalhado de envios, bloqueios e falhas.
- Registro local de produto, marketplace, horário e modo de envio.
- Trava persistente contra duplicação por 7 dias.
- Captura assistida de preços da Shopee.

## Instalação

1. Extraia o ZIP.
2. Abra `chrome://extensions`.
3. Ative o modo do desenvolvedor.
4. Remova a versão anterior.
5. Clique em **Carregar sem compactação**.
6. Escolha a pasta extraída e confirme a versão **1.0.11**.
