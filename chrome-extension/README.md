# ML Afiliados Sender

1. Abra `chrome://extensions` no Chrome.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione esta pasta `chrome-extension`.
5. Atualize o site ML Afiliados Pro, selecione as ofertas e clique em **ENVIAR PARA EXTENSÃO**.
6. No WhatsApp Web, escolha a conversa ou grupo e clique em **INICIAR** no painel.

Teste inicialmente com uma única oferta. A extensão interrompe a fila se a imagem não puder ser anexada.

Se houver falha, clique no ícone da extensão. O quadro de diagnóstico mostra a última etapa e a mensagem exata do erro.
